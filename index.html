The Model's Brain (Internal Memory)

How it stores memory: A simple frequency count table for each observed word in the training set (10 positive reviews, 10 negative reviews).
Word Positive Hits (+) Negative Hits (-) Tendency
How it stores memory: Each word has a dial (a floating-point numerical weight), plus an overall bias dial. Untrained: all dials are exactly 0.00. Training: nudges dials up or down based on errors.
Bias dial (\(b\)): 0.000

Word Weight Value (\(w\)) Influence
The Architecture: A single artificial neuron (Perceptron). It takes input word signals (\(x_i\)), multiplies each by its learned weight (\(w_i\)), sums them with the bias, and squashes the result through a Sigmoid activation curve to output a probability.
